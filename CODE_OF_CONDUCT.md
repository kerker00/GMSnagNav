# Code of Conduct

GMSnagNav adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

## Our pledge

We want participation in this project to be a harassment-free experience for everyone, regardless
of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity
and expression, level of experience, education, socio-economic status, nationality, personal
appearance, race, religion, or sexual identity and orientation. We act in ways that contribute to an
open, welcoming, diverse, inclusive and healthy community.

## Reporting

If you experience or witness unacceptable behavior, please report it privately to the maintainer
via GitHub ([@kerker00](https://github.com/kerker00)). All reports will be reviewed and handled
confidentially.

The full text of the Contributor Covenant, including enforcement guidelines, applies and is
available at the link above.
